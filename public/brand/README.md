# Marca Duelink

`duelink-logo-pixel.svg` é a marca principal da direção pixelada. Fundo transparente e geometria vetorial, com o letreiro convertido em curvas. Cores: creme `#f7f7e8`, verde-lima `#ceff3b`, roxo `#7023a3` e ameixa `#16071f`.

O nome usa letras contínuas para preservar a leitura. Os degraus e blocos estão na moldura, nas cartas conectadas e no contorno do símbolo. Conferido nos tamanhos de uso de 176 px e 125 px.

`duelink-logo-pixel.png` é uma exportação com transparência. `duelink-logo-pixel-preview.png` mostra a aplicação em fundo escuro e claro. `duelink-simbolo-pixel.svg` contém apenas o símbolo.

Base tipográfica: Chakra Petch Bold, convertida em curvas. Fonte oficial: https://github.com/google/fonts/tree/main/ofl/chakrapetch . As versões anteriores da marca permanecem nesta pasta para referência.
